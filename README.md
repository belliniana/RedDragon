# RedDragon Store

Projeto desenvolvido com Bootstrap 5 simulando uma loja virtual gamer moderna. O objetivo é demonstrar a utilização de componentes avançados do Bootstrap, responsividade, interatividade com JavaScript e organização de layout para e-commerce.

## Sobre o Projeto

A RedDragon Store é uma loja fictícia especializada em periféricos e equipamentos gamers.

O projeto apresenta uma interface moderna com produtos em destaque, sistema de carrinho, modal de detalhes e navegação responsiva.

## Tecnologias Utilizadas

- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
